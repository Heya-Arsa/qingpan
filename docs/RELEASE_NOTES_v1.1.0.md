# 清盘 v1.1.0

首个公开版本。一个原生 macOS 小工具：把文件按体积从大到小排好，勾选即可批量清理。

## 新增

- **三种扫描范围**：个人文件夹 / 全电脑（自动跳过 `/System`、`/usr`、`/Volumes`、`/private/var` 等系统位置）/ 自选文件夹
- **类型列 + 类型筛选**：图片、视频、音频、压缩包、PDF、文档、代码、应用、其他，每项带数量
- **排序**：体积 / 类型 / 时间 / 名称 / 位置，任一排序下同组内仍按体积降序
- **首屏视觉**：自转线框地球（经线 `scaleX` 交错动画）、大气光晕、倾斜轨道环
- **全盘进度**：按遍历文件数实时刷新，不再只在命中时跳动

## 主要功能

- 按体积降序排列，默认就是你要的顺序
- 批量选择：单击勾选、`Shift` 连选、`⌘A` 全选、一键「选前 10 大」
- 一键移到废纸篓，删除后可立即撤销，也能随时从废纸篓恢复
- 分析页：文件类型分布、占用最多的目录、体积最大的后缀、Top 10 大文件
- 状态页：磁盘余量、扫描设置、安全说明
- 全程本地离线，只读取体积与修改时间

## 安装

下载 `DiskSweeper-1.1.0.dmg`，双击挂载，把「清盘.app」拖到 Applications。

App 为 ad-hoc 签名、未做公证，首次打开若被 Gatekeeper 拦截：右键 → 打开，或到「系统设置 → 隐私与安全性」点「仍要打开」。

首次扫描「桌面 / 文稿 / 下载」时系统会询问文件夹权限，允许后结果才完整。

## 环境

- macOS 12 或更高
- 自行编译只需 Command Line Tools，无需 Xcode：`./build.sh`，打包 DMG 用 `./make_dmg.sh`

## 安全说明

删除一律走废纸篓，不做永久删除；只读取文件体积、修改时间与路径，不读取内容、不联网、不上传。
